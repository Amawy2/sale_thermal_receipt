# Sale Thermal Receipt (80mm) - Odoo 19.0

Print Odoo Sales Orders as clean receipts on **80mm thermal printers**.

- 80mm paper format with minimal margins
- Automatic page height based on the number of order lines
- Arabic / RTL layout
- "طباعة حراري" button in the Sales Order header + Print menu entry

## Installation
Copy `sale_thermal_receipt` into your addons path, update the Apps list and install **Sale Thermal Receipt (80mm)**.
