Sale Thermal Receipt (80mm)

Print your Sales Orders as clean receipts on 80mm thermal printers - in one click.

Key Features

  • Ready-made 80mm thermal paper format with minimal margins.
  • Automatic page height: the receipt length follows the number of order lines, so no wasted paper.
  • Full Arabic / RTL layout.
  • Company logo, name, phone and VAT number.
  • Order number, date, customer and salesperson.
  • Product lines with quantity, unit price, discount and subtotal; sections and notes are supported.
  • Untaxed amount, taxes and total in the order currency.
  • "طباعة حراري" / Thermal Print button in the Sales Order header, plus an entry in the Print menu.
  • No new models, no configuration: install and print.

How to use

  1. Install the module (it only depends on Sales).
  2. Open any Sales Order / Quotation.
  3. Click "طباعة حراري" in the header, or Print > إيصال حراري 80mm.
  4. Print the PDF on your thermal printer at 100% scale. Enabling the printer's auto-cut is recommended.

Using a 58mm printer? Change the width of the Thermal 80mm paper format (Settings > Technical > Reporting > Paper Format) to 58.
